Firehouse [Joseph Telecsan, Caleb Litman, Carter Shiplett]

This is the container repo that holds all of our codebase for our game design assignment.

We were tasked with creating a text-based firehouse game.
Game designed to have a gameplay loop of obtaining gear, saving people / animals through randomly generated scenarios, and racing against the clock to determine score.

This is intended to be a Java-based game, Java chosen simply because of its universal knowledge between the three of us.

Run the core text engine:

javac -d out src/firehouse/*.java
java -cp out firehouse.Main
