# firehouse

Branch for the fire station gear phase only (REQ-05).

## In scope

- Explore linked firehouse rooms with look, go, take, and inventory
- Collect turnout suit, crowbar, ladder, and keys
- Embark only after all four items are collected
- Shift timer still spends one minute per submitted command

## Out of scope

Truck map, neighborhood calls, scenario pool, rescues, and scoring (REQ-06 onward).
Embark ends the shift with a ready-for-dispatch message.
